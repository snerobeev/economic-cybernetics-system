
📅 Компонент	Роль
CostType------->Справочник конкретных видов затрат (энергия, зарплата, реклама и т.д.)
CostCategory--->Группировка затрат по категориям (материальные, трудовые, услуги и т.д.)
CostItem------->Конкретная запись о затрате: тип, сумма, дата, связь с продуктом
Product-------->Объект, к которому привязаны затраты

📅 Взаимосвязь:
CostItem содержит CostType

CostType знает свою CostCategory

Можно агрегировать затраты по категориям через CostType.getCategory()

📅 Зачем date:
Анализ по периодам Можно строить отчёты: затраты по месяцам, кварталам, годам.

Планирование бюджета Отличие между фактическими и плановыми затратами по датам.

Исторический учёт позволяет отслеживать динамику затрат и тренды.

Сравнение с другими данными Например, с производством, продажами, загрузкой ресурсов.

Финансовая отчётность Для бухгалтерии важно, когда именно была признана затрата.
